# brover_recognizer

ROS 2 пакет для сбора датасета, обучения YOLO classification модели и распознавания пользовательских классов объектов на BRover-E5.

## Возможности

- сбор изображений с камеры ровера по классам;
- подготовка датасета для YOLO classification;
- обучение модели на Raspberry Pi;
- запуск распознавания;
- публикация результата в ROS-топик;
- отображение результата в веб-интерфейсе BRover (опционально);
- возможность расширения количества распознаваемых классов до 9 штук.

## Быстрый сценарий работы

1. Настроить классы в `recognizer.yaml`.
2. Собрать датасет.
3. Подготовить датасет.
4. Обучить модель.
5. Запустить распознавание.
6. Проверить результат в терминале или веб-интерфейсе.
7. При необходимости очистить данные и начать цикл заново.

## Настройка классов

Классы настраиваются в файле:

```text
config/recognizer.yaml
```

Настроить классы необходимо **до начала сбора данных**.

Пример:

```yaml
/**:
  ros__parameters:
    classes:
      - classA
      - classB
```

Рекомендации по именам классов:

- лучше использовать латиницу, цифры и `_`;
- русский язык и пробелы технически возможны, но не рекомендуются;
- не стоит использовать `/`, `\`, `:`, кавычки и похожие символы.

Количество классов можно расширить до 9 штук. Для этого нужно добавить новые имена в список `classes`:

```yaml
/**:
  ros__parameters:
    classes:
      - classA
      - classB
      - classC
      - classD
```

После изменения списка классов новый датасет нужно собирать с учетом обновленного `recognizer.yaml`.

## Команды запуска

### Сбор датасета

```bash
ros2 launch brover_recognizer collect_dataset.launch.py
```

Клавиши:

- `1`, `2`, ... - сохранить изображение в соответствующий класс;
- `q` - выйти.

### Подготовка датасета

```bash
ros2 launch brover_recognizer prepare_dataset.launch.py
```

Команда раскладывает изображения в обучающую и проверочную выборки.

### Обучение модели

```bash
ros2 launch brover_recognizer train_model.launch.py
```

После обучения лучшая модель сохраняется в:

```text
~/brover_recognizer_data/models/best.pt
```

### Распознавание

```bash
ros2 launch brover_recognizer recognize.launch.py
```

Результат публикуется в топик:

```text
/brover_recognizer/result
```

Примеры сообщений:

```text
Найдено: classA: 95%
Ничего не распознано
```

### Очистка данных

```bash
ros2 launch brover_recognizer clear_data.launch.py
```

Команда полностью удаляет:

```text
~/brover_recognizer_data
```

Затем заново создает папки для сбора изображений по классам из текущего `recognizer.yaml`.

## Структура данных

Пакет хранит рабочие данные в домашней директории пользователя:

```text
~/brover_recognizer_data/
  dataset/
    raw/
    classification/
  models/
```

Назначение папок:

- `dataset/raw/` - исходные изображения, сохраненные при сборе датасета;
- `dataset/classification/` - подготовленный датасет для обучения YOLO classification;
- `models/` - результаты обучения и модель для запуска распознавания.

## Веб-интерфейс

Результат распознавания может отображаться в веб-интерфейсе BRover.

**Важно:** отображение результата в веб-интерфейсе работает только при использовании ветки `agro/final2026` пакета `brover_web`:

[https://github.com/voltbro/brover_web/tree/agro/final2026](https://github.com/voltbro/brover_web/tree/agro/final2026)

Если `brover_recognizer` не запущен, веб-интерфейс продолжает работать, а индикатор распознавания показывает, что распознавание не запущено.

## Рекомендации по датасету

- собирать изображения для каждого класса в похожем количестве;
- снимать объекты при разном освещении;
- менять расстояние и положение объекта в кадре;
- не смешивать несколько классов в одном кадре;
- не добавлять размытые или случайные кадры.
